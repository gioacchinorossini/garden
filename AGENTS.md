# Project Rules & Guidelines

## 1. Strict Adherence to User Instructions & Reference Designs
- **Follow Instructions Strictly**: Only implement exactly what the user asks for. Never add unrequested UI elements, extra summary labels, counts, filters, or additional features on your own.
- **Reference UI Mirroring**: When instructed to make a page similar to or match another page (e.g., matching the landowner request page UI), strictly mirror only the elements, layout, and structure that exist in that reference. Do NOT introduce unsolicited summary labels, headers, or embellishments.
- **No Unsolicited Additions**: Do not invent "helpful" or "nice-to-have" additions unless explicitly instructed by the user. Keep implementations clean, minimal, and 100% faithful to the requested specification.

## 2. Design System & Theme Consistency
- Strictly adhere to the existing Cats & Soup / Google Drive theme and class definitions in `assets/css/style.css`.
- Ensure responsive behavior mirrors the reference pattern without introducing divergent styling or unapproved components.
