# Strict Adherence to User Instructions

## Rule: No Unsolicited Additions
- **Follow Instructions Strictly**: Only implement exactly what the user asks for. Never add unrequested UI elements, extra summary labels, counts, filters, or additional features on your own.
- **Reference UI Mirroring**: When instructed to make a page similar to or match another page, strictly mirror only the elements, layout, and structure that exist in that reference. Do NOT introduce unsolicited summary labels, headers, or embellishments.
- **No Extra Embellishments**: Avoid adding unprompted widgets, helper text, or summary badges. Keep implementations strictly aligned with the exact requirements given.
