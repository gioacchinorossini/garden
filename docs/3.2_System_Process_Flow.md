# 3.2 System Process Flow

The **System Process Flow** illustrates how information moves across the **Idle Land for Community Gardening System**. It defines how data is captured, verified, shared, and updated among the three primary system actors: **Landowner**, **Gardener**, and **Administrator**.

---

## 3.2.1 High-Level Information Movement

The system operates around a central relational database ensuring verified, secure data handoffs:
1. **Land Onboarding & Legal Verification**: Landowners register parcel details and upload Land Registration Authority (LRA) verification documents (TCT/OCT, EPEB reference number, scanned deed). The Administrator audits the documents, verifying legitimacy before making the parcel publicly visible.
2. **Plot Application & Allocation**: Gardeners search verified lands via an interactive OpenStreetMap/Leaflet interface, inspect available sub-plots, and submit farming proposals. Landowners review incoming requests and approve or decline them, automatically updating plot occupancy.
3. **Collaboration & Harvest Tracking**: Approved gardeners and landowners collaborate through calendar schedules for community tasks (planting, watering, weeding). When crops mature, gardeners document their harvest yields (weight in kg, crop type, photos) for monitoring agricultural productivity.
4. **Governance & Analytics**: System administrators monitor platform activity, audit user accounts, and generate comprehensive utilization and yield reports.

## 3.2.2 Landowner Process Flow

```mermaid
flowchart TD
    Start([Start: Landowner Access]) --> HasAcc{Existing Account?}
    HasAcc -- No --> RegForm[Fill Landowner Registration Form<br/>Name, Email, Phone, Password]
    RegForm --> SaveUser[(Save to users table)]
    SaveUser --> Login[Landowner Login]
    HasAcc -- Yes --> Login
    
    Login --> Dashboard[Landowner Dashboard]
    Dashboard --> ActionChoice{Select Feature}

    %% Land Registration Subflow
    ActionChoice -->|Register Land| LandInfo[Enter Land Metadata:<br/>Listing Title, Address, Total Area]
    LandInfo --> MapCoords[Select GPS Coordinates on Leaflet Map<br/>Latitude & Longitude]
    MapCoords --> LRADocs[Input LRA Verification Details:<br/>Title Type, Title No, ROD Branch, EPEB No]
    LRADocs --> UploadFiles[Upload Scanned Title CTC & LRA Receipt]
    UploadFiles --> PlotSetup[Define Plots / Divisions]
    PlotSetup --> SubmitLand[(Store in lands & plots<br/>Status: Pending)]
    SubmitLand --> AwaitAdmin[Await Administrator Review]
    
    AwaitAdmin --> AdminResult{Verification Result}
    AdminResult -- Rejected --> ReadReason[Read Admin Rejection Notes]
    ReadReason --> LandInfo
    AdminResult -- Approved --> LandActive[Land Published: Active & Discoverable]

    %% Request Management Subflow
    ActionChoice -->|Review Requests| ViewRequests[Access Plot Application Inbox]
    ViewRequests --> PendingRequests{New Requests?}
    PendingRequests -- No --> Dashboard
    PendingRequests -- Yes --> AssessReq[Examine Gardener Profile, Proposed Crop, & Duration]
    AssessReq --> ReqDecision{Application Decision}
    ReqDecision -- Reject --> DenyReq[(Update requests: status = rejected)]
    ReqDecision -- Approve --> GrantReq[(Update requests: status = approved<br/>Update plots: status = occupied)]
    DenyReq --> Dashboard
    GrantReq --> Dashboard

    %% Gardening Schedules
    ActionChoice -->|Manage Activities| SchedEvents[Create / Update Garden Events]
    SchedEvents --> SchedInputs[Input Task Type, Date, Time & Plot]
    SchedInputs --> SaveSched[(Store in schedules table)]
    SaveSched --> Dashboard

    ActionChoice --> Logout([Logout])
```

## 3.2.3 Gardener Process Flow

```mermaid
flowchart TD
    Start([Start: Gardener Access]) --> HasAcc{Existing Account?}
    HasAcc -- No --> RegForm[Fill Gardener Registration Form<br/>Name, Email, Phone, Password]
    RegForm --> SaveUser[(Save to users table)]
    SaveUser --> Login[Gardener Login]
    HasAcc -- Yes --> Login

    Login --> Dashboard[Gardener Dashboard]
    Dashboard --> NavChoice{Select Action}

    %% Browse & Discovery
    NavChoice -->|Explore Lands| MapDirectory[Browse Interactive Map & Land Catalog]
    MapDirectory --> SearchFilter[Filter by Location, Available Plots, Land Area]
    SearchFilter --> LandDetails[View Land Details, Photos & Available Plots]
    
    LandDetails --> ApplyCheck{Apply for Plot?}
    ApplyCheck -- No --> MapDirectory
    ApplyCheck -- Yes --> FillApp[Complete Application Form:<br/>Select Plot, Intended Duration, Farming Purpose]
    FillApp --> SaveReq[(Save to requests table<br/>Status: Pending)]
    SaveReq --> AwaitReview[Wait for Landowner Evaluation]

    AwaitReview --> ReqOutcome{Request Outcome}
    ReqOutcome -- Rejected --> RejNotice[Status: Declined]
    RejNotice --> Dashboard
    ReqOutcome -- Approved --> AppNotice[Status: Approved - Plot Assigned]
    AppNotice --> ActivePlot[Start Garden Project]

    %% Task Schedules
    NavChoice -->|Check Schedules| ViewSched[View Activity Calendar]
    ViewSched --> AttendTask[Participate in Garden Maintenance Tasks<br/>Planting, Watering, Weeding]
    AttendTask --> Dashboard

    %% Harvest Recording
    NavChoice -->|Record Harvest| HarvestLog[Open Harvest Log Entry]
    HarvestLog --> HarvestData[Input Crop Name, Harvested Weight kg, Date, Notes]
    HarvestData --> HarvestImg[Upload Crop / Harvest Photo]
    HarvestImg --> SaveHarvest[(Save to harvests table)]
    SaveHarvest --> Dashboard

    NavChoice --> Logout([Logout])
```

## 3.2.4 Administrator Process Flow

```mermaid
flowchart TD
    Start([Start: Administrator Access]) --> AdminLogin[Secure Admin Authentication]
    AdminLogin --> Dashboard[Admin Control Panel Dashboard]
    Dashboard --> AdminModule{Select Management Module}

    %% Land Title Verification Module
    AdminModule -->|Land Title Verification| FetchPending[(Fetch lands WHERE status = 'pending')]
    FetchPending --> AuditLand[Inspect Land Dossier:<br/>Coordinates, Boundary Area, Address]
    AuditLand --> AuditLRA[Review LRA Verification Dossier:<br/>Registry of Deeds Branch, Title Number,<br/>EPEB Transaction No., Scanned CTC & Receipt]
    AuditLRA --> TitleValid{Documents Legitimate?}

    TitleValid -- No --> RejectLand[Set Status: Rejected<br/>Enter Rejection Reason Notes]
    RejectLand --> SaveRej[(Update lands table)]
    SaveRej --> AlertOwner[Send Notification to Landowner]
    AlertOwner --> Dashboard

    TitleValid -- Yes --> ApproveLand[Set Status: Approved<br/>Set is_lra_verified = 1]
    ApproveLand --> SaveApp[(Update lands table)]
    SaveApp --> PublishLand[Parcel Published for Gardeners]
    PublishLand --> Dashboard

    %% User Management Module
    AdminModule -->|User Management| FetchUsers[(Query users table)]
    FetchUsers --> AuditUsers[Inspect User Profiles & Activity History]
    AuditUsers --> UserAction{Select Moderation Action}
    UserAction --> ToggleStatus[Toggle Account Status: Active / Inactive]
    ToggleStatus --> SaveUserMod[(Update users table)]
    SaveUserMod --> Dashboard
    UserAction --> NoChange[Keep Active] --> Dashboard

    %% Reporting & Analytics Module
    AdminModule -->|Reports & Analytics| ChooseReport[Select Analytical Report]
    ChooseReport --> ReportType{Report Focus}
    ReportType --> LandStats[Land Allocation & Plot Utilization Rates]
    ReportType --> YieldStats[Community Crop Yields & Harvest Output]
    ReportType --> UserGrowth[User Demographics & Participation Trends]

    LandStats --> GenReport[Aggregate Cross-Table Metrics]
    YieldStats --> GenReport
    UserGrowth --> GenReport
    GenReport --> ExportReport[Export / Print System Report Summary]
    ExportReport --> Dashboard

    AdminModule --> Logout([Logout])
```

## 3.2.5 Data Entity Handoff Matrix

| Stage | Triggering Actor | Data Transmitted | Receiving Component | Impact on System State |
| :--- | :--- | :--- | :--- | :--- |
| **Land Registration** | Landowner | Title, Geo-coordinates, Area, Title Type, EPEB No, Scans | Admin Queue (`lands`) | New record with `status = 'pending'`, `is_lra_verified = 0` |
| **Verification Review** | Administrator | Approval or Rejection status + feedback | Landowner / Public Listing | `status = 'approved'`, `is_lra_verified = 1`; plots open for search |
| **Plot Request** | Gardener | Plot ID, Garden plan, Duration | Landowner Inbox (`requests`) | New request record with `status = 'pending'` |
| **Plot Decision** | Landowner | Approval or Rejection response | Gardener Notification / Plot | `requests.status = 'approved'`, `plots.status = 'occupied'` |
| **Task Scheduling** | Landowner / Gardener | Task title, category, date/time range | Calendar System (`schedules`) | Shared calendar entry displayed on dashboard |
| **Harvest Recording** | Gardener | Crop type, quantity (kg), photo, date | Harvest Registry (`harvests`) | Appended to community agricultural yield tracking |
| **System Reporting** | Administrator | Date filters, category parameters | Reporting Engine | Real-time aggregate SQL statistics & visual chart outputs |
